Gemini Key Not Working? Fix the Common ErrorsGemini key کام نہیں کر رہی؟ عام غلطیاں اور ان کا حل

The most common problem new users face is not the app — it is the Gemini key. The assistant stays silent, or shows an error, and it feels like the app is broken. In almost every case one of the five things below is the reason, and each one takes a minute to fix. These steps work for both the Android app and the PC assistant.نئے صارفین کو سب سے عام مسئلہ ایپ کا نہیں ہوتا — Gemini key کا ہوتا ہے۔ اسسٹنٹ خاموش رہتا ہے یا error دکھاتا ہے اور لگتا ہے ایپ خراب ہے۔ تقریباً ہر بار وجہ نیچے والی پانچ چیزوں میں سے ایک ہوتی ہے، اور ہر ایک کا حل ایک منٹ کا ہے۔ یہ قدم Android ایپ اور PC اسسٹنٹ، دونوں کے لیے ہیں۔

1. “API key not valid” — the key was pasted wrong۱۔ ”API key not valid“ — key غلط paste ہوئی

This is the number one cause. The key was copied with a missing character, an extra space at the start or end, or an old key that was later deleted in AI Studio. Fix: open aistudio.google.com, create a fresh key, copy it fully, and paste it into the app's Settings in one go — do not type it by hand. If you saved the key before, delete the old text completely first, then paste.یہ سب سے بڑی وجہ ہے۔ key کاپی کرتے ہوئے کوئی حرف رہ گیا، شروع یا آخر میں space آ گیا، یا پرانی key لگی ہے جو بعد میں AI Studio سے delete ہو چکی تھی۔ حل: aistudio.google.com کھولیں، نئی key بنائیں، پوری کاپی کریں اور ایپ کی Settings میں ایک ہی بار paste کر دیں — ہاتھ سے ہرگز نہ لکھیں۔ اگر key پہلے سے لکھی ہے تو پہلے پرانا متن مکمل مٹائیں، پھر paste کریں۔

2. “Quota exceeded” or error 429 — the free limit is finished for now۲۔ ”Quota exceeded“ یا error 429 — مفت حد عارضی طور پر ختم

The free Gemini key has a daily and per-minute limit, and it is yours alone: heavy use, or many long chats in a short time, can finish it. This is not a fault in your key. Fix: wait a while (the per-minute limit resets in a minute; the daily limit resets the next day). If you need more, create a key in a second Google project in AI Studio and use that one.مفت Gemini key کی روزانہ اور فی منٹ ایک حد ہوتی ہے۔ زیادہ استعمال، یا تھوڑے وقت میں بہت سی لمبی باتیں، اس حد کو ختم کر سکتی ہیں۔ یہ آپ کی key کی خرابی نہیں ہے۔ حل: کچھ دیر انتظار کریں (فی منٹ والی حد ایک منٹ میں بحال ہو جاتی ہے؛ روزانہ والی اگلے دن)۔ اگر زیادہ ضرورت ہو تو AI Studio میں دوسرے Google project کی key بنا کر وہ لگا لیں۔

3. “Model not found” or error 404 — the app version is old۳۔ ”Model not found“ یا error 404 — ایپ کا ورژن پرانا ہے

Google retires older Gemini models over time. Very old versions of the app may ask for a model that no longer exists. Fix: download the latest version of Shahzaib AI from this website's homepage and install it over the old one — your khata, settings and key stay saved. The current version tries several current models one by one, so this error should not appear.Google وقت کے ساتھ پرانے Gemini models بند کر دیتا ہے۔ ایپ کے بہت پرانے ورژن ایسے model کو بلا سکتے ہیں جو اب موجود نہیں۔ حل: اسی ویب سائٹ کے homepage سے Shahzaib AI کا تازہ ترین ورژن ڈاؤن لوڈ کر کے پرانے کے اوپر انسٹال کر لیں — آپ کا کھاتہ، settings اور key محفوظ رہیں گے۔ موجودہ ورژن کئی تازہ models کو ایک ایک کر کے آزماتا ہے، اس لیے یہ error نہیں آنا چاہیے۔

4. The key is saved, but the assistant still does not reply۴۔ key save ہے، پھر بھی اسسٹنٹ جواب نہیں دیتا

Check three things in order. One: is the internet on? AI chat needs a connection (prayer times, khata and reminders work offline, chat does not). Two: open Settings and save the key once more — sometimes an earlier save did not complete. Three: close the app fully and open it again. On PC, also make sure you pressed the save/apply button in the Settings panel after pasting the key.تین چیزیں ترتیب سے دیکھیں۔ ایک: انٹرنیٹ آن ہے؟ AI بات چیت کے لیے کنکشن چاہیے (نماز کے اوقات، کھاتہ اور یاد دہانیاں آف لائن چلتی ہیں، بات چیت نہیں)۔ دو: Settings کھول کر key ایک بار پھر save کریں — کبھی پہلی save مکمل نہیں ہوتی۔ تین: ایپ کو مکمل بند کر کے دوبارہ کھولیں۔ PC پر یہ بھی دیکھ لیں کہ key paste کرنے کے بعد Settings پینل میں save/apply کا بٹن دبایا تھا۔

5. “Permission denied” or error 403 — the key was made in the wrong place۵۔ ”Permission denied“ یا error 403 — key غلط جگہ سے بنی

A key created deep inside Google Cloud Console may not have the Gemini API enabled, and the assistant gets a 403. Fix: do not fight with console settings — simply create the key in Google AI Studio (aistudio.google.com → Get API key → Create API key). Keys made there work straight away. Our step-by-step guide is linked below.Google Cloud Console کے اندر جا کر بنائی گئی key پر Gemini API فعال نہ ہو تو اسسٹنٹ کو 403 ملتا ہے۔ حل: کنسول کی settings سے نہ لڑیں — بس Google AI Studio (aistudio.google.com ← Get API key ← Create API key) سے key بنائیں۔ وہاں بنی key فوراً چلتی ہے۔ ہماری قدم بہ قدم گائیڈ نیچے linked ہے۔

Three golden rules for your keyآپ کی key کے تین سنہرے اصول

One: never share your key with anyone — not on WhatsApp, not in a screenshot. Anyone with your key uses your free quota. Two: only ever create your key at aistudio.google.com; any website or person selling or “giving” keys is not safe. Three: always run the latest version of the app from this website, so model changes never break your assistant.ایک: اپنی key کسی کے ساتھ share نہ کریں — نہ WhatsApp پر، نہ screenshot میں۔ جس کے پاس key ہو، وہ آپ کی مفت حد استعمال کر سکتا ہے۔ دو: key ہمیشہ صرف aistudio.google.com سے بنائیں؛ کوئی ویب سائٹ یا شخص key بیچے یا ”دے“ تو وہ محفوظ نہیں۔ تین: ایپ کا تازہ ترین ورژن ہمیشہ اسی ویب سائٹ سے رکھیں، تاکہ models کی تبدیلی آپ کے اسسٹنٹ کو کبھی نہ روکے۔
