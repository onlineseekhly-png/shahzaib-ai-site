انسٹال کرنے کا طریقہ

تقریباً 3 منٹ لگتے ہیں۔ فون Android ہونا چاہیے۔

  1. ShahzaibAI.apk ڈاؤن لوڈ کریں (فائل Downloads میں آئے گی)۔
  2. فائل کھولیں۔ Android "اس ذریعے سے انسٹال" کی اجازت مانگے تو Allow دے دیں۔
  3. اگر Play Protect انتباہ دے تو More details ← Install anyway دبائیں۔ یہ ایپ Play Store سے باہر ہے، اس لیے ہر ایسی ایپ پر یہ آتا ہے۔
  4. ایپ کھولیں اور مائیک جیسی اجازتیں اپنی مرضی سے دیں۔ جو اجازت نہ دیں وہ خصوصیت بند رہے گی۔
  5. Gemini key لگائیں (نیچے طریقہ لکھا ہے) اور ترتیبات میں پیسٹ کریں۔
  6. ہو گیا! اب بولیں یا لکھیں۔

مفت Gemini key کیسے بنائیں

  1. aistudio.google.com/apikey کھولیں اور اپنے Google اکاؤنٹ سے لاگ اِن ہوں۔
  2. Create API key دبائیں۔
  3. جو لمبی key (AIza… سے شروع) ملے اسے کاپی کریں۔
  4. ایپ کی ترتیبات میں key کے خانے میں پیسٹ کر کے محفوظ کریں۔
اپنی key کسی کو نہ دیں اور اسے اسکرین شاٹ میں نہ دکھائیں۔ مفت key کی روزانہ حد ہوتی ہے، حد ختم ہو تو ایپ پیغام دیتی ہے۔ ہر شخص اپنی الگ key رکھے۔
