مفت Gemini API key کیسے بنائیں (قدم بہ قدم)

اگر آپ کوئی AI ایپ استعمال کرنا چاہتے ہیں جو آپ کی اپنی "کنجی" مانگتی ہو، تو اسے API key کہتے ہیں۔ Google کا Gemini ماڈل چلانے کے لیے یہ key Google AI Studio سے مفت بن جاتی ہے۔ ذیل میں پورا طریقہ ہے۔

قدم 1: AI Studio کھولیں

براؤزر میں aistudio.google.com/apikey کھولیں اور اپنے Google (Gmail) اکاؤنٹ سے لاگ اِن ہوں۔

قدم 2: Key بنائیں

Create API key دبائیں۔ اگر وہ کوئی پروجیکٹ چننے کو کہے تو نیا پروجیکٹ بنا لیں یا موجود چن لیں۔

قدم 3: Key کاپی کریں

جو لمبی عبارت (عموماً AIza سے شروع) نظر آئے اسے کاپی کر لیں۔

قدم 4: ایپ میں لگائیں

شہزیب AI کی ترتیبات کھول کر key کے خانے میں پیسٹ کریں اور محفوظ کریں۔ ایپ ایک سے زیادہ keys بھی رکھ سکتی ہے؛ ایک کی حد ختم ہو تو دوسری سے کام چلا لیتی ہے۔

اہم باتیں

  • مفت key کی روزانہ اور فی منٹ حد ہوتی ہے۔ زیادہ استعمال پر "حد ختم" کا پیغام آ سکتا ہے، کچھ دیر بعد دوبارہ چلتی ہے۔
  • Gemini کی بولنے والی آواز (TTS) کی مفت حد اور بھی کم ہوتی ہے۔ ایسی صورت میں ایپ فون کی اپنی آواز سے کام لیتی ہے۔
  • Key کسی کو نہ دیں، اور اس کی تصویر یا اسکرین شاٹ شیئر نہ کریں۔ اگر غلطی سے کھل جائے تو AI Studio میں پرانی key ہٹا کر نئی بنا لیں۔
  • Google کی شرائط اور مفت حدیں بدلتی رہتی ہیں؛ تازہ تفصیل AI Studio پر دیکھیں۔
