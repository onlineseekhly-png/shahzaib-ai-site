How to Get a Free Gemini API Key (Step by Step)گائیڈ: مفت Gemini API key کیسے بنائیں

Some AI apps ask you for your own API key instead of charging a subscription. For Google's Gemini models, you can create one for free in Google AI Studio. Here is the whole process.کچھ AI ایپس سبسکرپشن لینے کے بجائے آپ سے آپ کی اپنی API key مانگتی ہیں۔ Google کے Gemini ماڈل کے لیے یہ key Google AI Studio سے مفت بن جاتی ہے۔ پورا طریقہ یہ ہے۔

Step 1: Open AI Studioقدم 1: AI Studio کھولیں

Go to aistudio.google.com/apikey and sign in with your Google (Gmail) account.aistudio.google.com/apikey کھولیں اور اپنے Google (Gmail) اکاؤنٹ سے لاگ اِن ہوں۔

Step 2: Create the keyقدم 2: Key بنائیں

Tap Create API key. If it asks for a project, create a new one or pick an existing one.Create API key دبائیں۔ پروجیکٹ کا پوچھے تو نیا بنائیں یا موجود چنیں۔

Step 3: Copy itقدم 3: کاپی کریں

Copy the long text, usually starting with AIza.جو لمبی عبارت (عموماً AIza سے شروع) نظر آئے اسے کاپی کر لیں۔

Step 4: Paste it into the appقدم 4: ایپ میں لگائیں

Open the Settings of Shahzaib AI, paste the key and save. You can add more than one key; if one reaches its limit the app tries the next.شہزیب AI کی ترتیبات کھول کر key پیسٹ کریں اور محفوظ کریں۔ ایک سے زیادہ keys بھی رکھ سکتے ہیں؛ ایک کی حد ختم ہو تو ایپ اگلی آزماتی ہے۔

Things to knowاہم باتیں

  • Free keys have per-minute and per-day limits. If you hit them, wait a while or add another key.مفت key کی فی منٹ اور فی دن حد ہوتی ہے۔ حد ختم ہو تو کچھ دیر رکیں یا دوسری key شامل کریں۔
  • Spoken Gemini voices have an even smaller free allowance. The app falls back to your phone's own voice when that runs out.Gemini کی بولنے والی آواز کی مفت حد اس سے بھی کم ہے۔ وہ ختم ہو تو ایپ فون کی اپنی آواز استعمال کرتی ہے۔
  • Never share your key or post a screenshot of it. If it leaks, delete it in AI Studio and make a new one.اپنی key کسی سے شیئر نہ کریں اور اس کا اسکرین شاٹ نہ لگائیں۔ کھل جائے تو AI Studio میں ہٹا کر نئی بنائیں۔
  • Google changes free limits and terms from time to time, so check AI Studio for the current ones.Google مفت حدیں اور شرائط بدلتا رہتا ہے، اس لیے تازہ تفصیل AI Studio پر دیکھیں۔
