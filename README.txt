Shahzaib AI website (static). GitHub Pages par bina kisi build ke chalti hai.
1) config.js mein apna githubUser aur email likhen.
2) sitemap.xml aur robots.txt mein YOUR_USERNAME / YOUR_SITE_REPO apne asal naam se badal den.
3) img/ mein shot1.png ... shot4.png (phone ke asal screenshots) rakhen aur index.html mein shot-wale dabbe <img src="img/shot1.png"> se badal den.
